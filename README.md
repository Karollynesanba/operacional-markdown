# Playbooks operacionais da Assessoria GREAT

Documentação operacional convertida integralmente a partir dos nove PDFs fornecidos. Consulte o [sumário](SUMMARY.md) para navegar por estratégia, posicionamento, tráfego e produção.

Cada documento possui uma página Markdown própria, organizada na mesma sequência do PDF. O conteúdo foi incorporado ao site como títulos, parágrafos, listas, tabelas e fluxos textuais. As páginas não usam fotografias ou capturas dos PDFs.

Nenhuma regra, etapa, observação, exemplo ou parâmetro numérico foi intencionalmente resumido. Quando fontes diferentes apresentam informações divergentes, cada versão permanece no respectivo documento de origem.
